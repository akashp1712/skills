# Launch post — and-nothing-else

Text post. The temptation log is the screenshot, not a carousel.

---

## LinkedIn

> I asked Claude to fix a typo.
>
> It fixed the typo. It also reformatted the file, extracted a Heading component, and rewrote the sentence to be punchier.
>
> I built a skill whose only job is to not do that.
>
> After every edit it has to print a temptation log — what it wanted to do, and did not:
>
> DID      fix the typo in the heading
> CHANGED  page.tsx — Recieve → Receive
> NOT      reformat the file
>          rewrite the heading to be punchier
>          extract the heading into a Heading component
>
> The `NOT` column is the product. Helpfulness is the bug.
>
> npx skills add akashp1712/skills --skill and-nothing-else
>
> MIT. Take it.
